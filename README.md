# Newspaper Layout Webpage

This is a simple newspaper-style webpage created using HTML and CSS. The project demonstrates how to design a newspaper layout with headlines, a scrolling news banner, and multiple content columns. 


## Features

* Newspaper-inspired design
* Scrolling news headline using marquee
* Multi-column article layout
* Simple and clean CSS styling
* Full-page content section

## Technologies Used

* HTML
* CSS



## How to Run

1. Download or clone the repository.
2. Open the project folder.
3. Double-click the `index.html` file or open it in any web browser.

## Learning Objectives

This project helped me practice:

* Creating web pages using HTML
* Styling content with CSS
* Using multi-column layouts
* Working with headings and paragraphs
* Designing a newspaper-style interface
